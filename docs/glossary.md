# Glossary

| Term | Definition |
|------|------------|
| Garage | Collection of a user's vehicles |
| Vehicle Profile | Digital identity of a vehicle |
| Maintenance Record | Logged service activity |
| Service Reminder | Scheduled maintenance notification |
| Expense | Money spent on vehicle ownership |
| Document Vault | Secure storage for vehicle documents |
| Marketplace | In-app ecosystem for automotive products and services |
| Workshop | Service provider performing vehicle maintenance |
| Digital Vehicle Passport | Comprehensive ownership history and verified records |
